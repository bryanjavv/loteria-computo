# Lotería de Arquitectura de Cómputo

Juego multijugador interactivo en tiempo real basado en la Lotería Mexicana tradicional con temática de conceptos de Arquitectura de Computadoras (CPU, RAM, ALU, Kernel, Buses, etc.).

## 🚀 Tecnologías
* **Frontend:** HTML5, CSS3 (estética estilo Gartic Phone), JavaScript Vanilla.
* **Backend:** Node.js, Express, Socket.io.
* **Infraestructura:** Oracle Cloud Infrastructure (Ubuntu Linux), PM2, Nginx.

## 🎮 Características
* Salas privadas con código de acceso temporal para invitados.
* Mazo temático con audios rápidos generados por TTS.
* Modos de juego: Línea recta, 4 esquinas, el centro y cartón lleno.
* Validación estricta en servidor y sistema de Power-ups aleatorios.
